How this page reaches you

A hostname is resolved using DNS. Your browser connects to the hosting service and requests the page over HTTPS. The tests in the coursework report measure the actual environment; this diagram describes the usual TCP based connection.

  1. DNS lookup
  2. TCP connection
  3. TLS handshake
  4. HTTP request and response

DNS resolves names to addresses. TCP provides a reliable byte stream. TLS encrypts the HTTP exchange. An HTTPS packet capture normally exposes connection and TLS metadata, while the page content remains encrypted.

Browsers may reuse cached DNS records and established connections. HTTP/3, when negotiated, uses QUIC over UDP; the protocol actually observed must be checked in the capture.
